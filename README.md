# Hi, I'm Frederick Abalo

I build geospatial software: data pipelines, mapping applications, and backend systems that turn imagery, terrain, and spatial datasets into tools people can use.

My background includes mapping and geospatial engineering at **Zipline**, supporting autonomous delivery, and building **[Geomersive](https://geomersive.org)**. I work across Python services, PostgreSQL/PostGIS, spatial QA, cloud infrastructure, and production support. I'm also pursuing a Master of Urban Spatial Analytics at the University of Pennsylvania.

Much of my professional work is proprietary. These public repositories offer a separate, inspectable view of my engineering approach, using public or synthetic data.

## Geomersive

I own Geomersive and work on its spatial-data application: dataset and product catalogs, PostGIS-backed metadata, upload workflows, mapping viewers, and processing workers. The application code is private and remains under development. The [public website](https://geomersive.org) introduces the business; the [tile utilities](https://github.com/GeomersiveTeam/geomersive-tile-utils) provide a small public code example. These links are not claims that every planned platform feature is deployed.
